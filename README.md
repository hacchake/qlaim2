# QLAIM 2
Qix風の陣取りアーケード「QLAIM」の続編。スプラトゥーンのようなナワバリ争いを足していく版です。
`index.html` をブラウザで開くだけで遊べます(QLAIM 1 は別リポジトリ hacchake/qlaim)。

## QLAIM 2 で変わったこと
- **自由移動**: 平面では、上下左右だけでなく斜めにもなめらかに進み、思った形に線を引ける(キーの同時押し・スティックのアナログ)
- **VS ナワバリバトル**(最初のモード): 自機と同じことができるCPUと、90秒で陣地の広さを競う。**全員敵同士**。ラウンドごとに平面 → 立体へ進む
  - CPUは3人から、2ラウンドごとに1人ずつ増えて7人まで。色は 赤(自分)・黄・青・緑・紫・オレンジ・ピンク・水色
  - 自分がいちばん広ければ勝ち。上のバーに全員の割合と自分の順位
  - CPUも線を引いて自分の色で陣地を取り、自機の描きかけの線を切りにくる
  - CPUの描きかけの線に触れる・陣地で囲むとCPUはダウン(少しあとに戻る)。ヌメリンやバチッコもCPUに当たる
  - 時間切れ(か合計の占領率が目標)で、広いほうが勝ち。負けると残機を1つ使ってやり直し
  - エリアが進むほどCPUが速く、ずる賢くなる
- **PARTY 3チーム対戦**: 赤・黄・青の3チーム。ロビーで色ごとに「人間 / CPU」を選ぶ(タップか ←→)。1チームの人数(1〜5人、2人目からCPU。ぜんぶで15人まで)とCPUの強さも選べる。スタート地点は外周を人数で等分し、赤・黄・青の順に交互
  - P1 = WASD + 左Shift / P2 = 矢印 + 右Shift / P3 = IJKL + ] 。ゲームパッドはつないだ順に P1〜P3、タブレットのスティックは P1
  - 全員同じルール: 線を切られる・囲まれる・敵に当たるとダウンして少しあとに戻る。90秒で一番広いチームの勝ち
  - ラウンドが進むと盤面が変わる(平面 → 立方体 → 球 → …)。立体では各チームの基地がいちばん遠い場所に作られ、そのふちから出発
  - 立体で人間が2〜3人なら、画面を上下に分けてそれぞれの人のまわりを映す(操作の向きも自分の画面どおり)
  - やられると魂が昇っていき、復活の前に画面の上から魂が戻る場所まで飛んでくる。味方の線は切れない
- 対戦モードの色: 赤系・黄系・青系の中で、陣地を取るたびに色が少しずつ揺らぐ(VS は自機が赤、CPUは青・黄)
- アイテム「上塗り」(⟳、対戦モードだけ。PARTY は6秒ごとに出る): しばらく陣地の上も走れて、通ったところを塗る。相手の陣地は2色が混ざって中立(赤+黄=オレンジ / 赤+青=紫 / 黄+青=緑。だれのものでもない)、中立をもう一度塗ると自分の陣地
- 描いているときの音は、チームごとに和音の担当(根音・3度・5度)。何人も同時に描くと曲に合った和音になる

## 操作
- 矢印 / WASD / 画面をなぞる / ゲームパッド: 移動
- 空き地へ進むとそのまま線を引く(ゆっくり・×2点)。Z / スペースを押している間だけ速く引く(×1点)
- X を押す間: カメラが引いて立体の全体が見える
- P: ポーズ(つづける / はじめから / OPTIONS / あそびかた / タイトルへ)、H: あそびかた、M: 消音、C: スクリーンショット
- ゲームオーバー画面: S = 結果をシェア、R = すぐもう一度

## 遊びかた
- 線で囲んで陣地を広げ、目標の占領率でクリア。続けて囲むとコンボ、ヌメリンが線をかすめるとニアミスボーナス
- アイテムは線で囲むと手に入る: S=敵がゆっくり ◆=1回ミスを防ぐ ★=得点2倍 ♥=1UP ✦=バチッコ一掃 ≋=虹色インク ✺=インクがはじける ◐=ローラーの色が変わる
- INK テーマでは線を閉じるたびにインクの色が変わる(ローラーの色 = 次に塗る色)。★の間は金、≋の間は虹色の帯でレインボーアートに
- 球(SPHERE)は色塗りではなく、囲むと地球の地図がだんだんあらわれる(スタートは日本)。地図データは Natural Earth(パブリックドメイン)
- 地球では、囲んだ陸から7つの大陸を発見していく(全部見つけると実績「世界一周」)
- クリアした盤面は作品としてギャラリーに残る(最新24枚。タイトルで G)
- 勝負がつくと「しゅうりょう!」のあと結果の表(順位・広さ・たおした数・やられた数。PARTY は MVP も)
- OPTIONS「対戦の設定・キー」: VS の CPU の数(AUTO / 1〜7)・CPU の強さ・試合時間(60〜180秒)・ステージ(TOURの順 / ランダム / 好きな1つ)・キーコンフィグ(P1〜P3 の上下左右と「速く」。P1 のキーはひとりのときも使える)
- 対戦中はCPUどうしで「そもさん!」「せっぱ!」のような掛け合いをする(自機が返すことも)
- 対戦モードでコンボが続くと、チームの色のまま柄が出る: 1 = 市松 / 2 = 麻の葉 / 3〜 = フラワー・オブ・ライフ
- スマホ・タブレットは左下のアナログスティックで操作(親指をすべらせた向きに進む)
- 陣地のあいだの線は、となりの陣地の色がにじんで縫い合わさる
- 塗る音は6種類(もとの音・アルペジオ・無限音階・ハープ・鐘・スタブ)。OPTIONS「塗る音」で選べる。線を描く音は無限音階で、伸ばすほど終わりなく上がり続ける
- 塗った陣地には、そのときの状況で模様がつく: ふつう=グラデーション / 大きく取る=波紋 / じっくり描く=うずまき / SLOW中=波 / コンボ=ストライプ・チェック / STAR中=金の水玉
- OPTIONS「インク」で MIX(いろいろ)・RAINBOW(いつも虹)・好きな1色を選べる
- AREA 3 から ヌメリン2体(分断で即クリア)、AREA 4 から オイカケ(線を追ってくる。囲めば倒せる)
- 5エリアごとに BONUS AREA(40秒で好きなだけ囲む)、AREA 6 から ヌメリンがときどき突進(白く光って予告)
- ゲームオーバー後10秒はコンティニューできる(スコアは0から。ハイスコアは残る)
- TOURの全22面を制覇するとエンディング

## buddy たち(18種)
Clawd の仲間が総出演。迷子の味方(アヒル・ウーパールーパー・カメ・カピバラ・フクロウ・ロボ・ブロブ)は囲んで助けるとごほうび。
陣地をかじるカタツムリ・キノコ、墨で穴をあけるタコ、アイテム泥棒のガチョウ、通せんぼのネコ・デブネコ、
線に触れるとミスのサボテン・ウサギ・ペンギン・ユーレイ・ドラゴン。タイトルで B = buddy図鑑
みんな名前・レア度・性格・ステータスを持っていて、ときどきしゃべる(カメのワーブルは急がないのに、いつも正しい)。
ステータスは動きにも出る(のんびり屋はゆっくり、CHAOS が高いといたずらが多い)。まれに色違いも。
図鑑で選んで Z を押すと、ステータスつきのカードが見られる

Clawd も場面に合わせてしゃべる。ときどきレアなセリフや、季節・曜日・時間に合わせた時事ネタも
